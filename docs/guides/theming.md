# Theming and branding

Themes control colors, fonts and spacing across every page of an app. A theme is set once for the app and applies to the pages you add later.

## Tokens

Each theme defines a primary color, a surface color, a text color and one font pair. Components read these tokens, so changing the primary color updates every button and link at once.

## Dark mode

Dark mode is generated from the light palette. It follows the visitor system setting unless the theme locks one mode.

## Favicons and titles

The favicon is shared by all pages. The browser title of a page comes from the title given when the page is created and can be edited later in the page settings.

## Quick facts

- Colors defined per theme: primary, surface and text
- Fonts per theme: 1 pair
- Dark mode follows the system setting: yes
