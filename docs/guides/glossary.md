# Glossary

## App

The top level container of pages, databases, forms and settings. Created with the `create_app` workflow.

## Component

A block placed on a page, such as a button or a chart.

## Deployment

A published copy of an app in one environment. Every `publish_site` call creates one.

## Field

A typed column of a table, added with `add_field`.

## Record

One row of a table.

## Relation

A link between two tables of the same database.

## Slug

The URL segment of a page, written in lowercase with dashes.

## Workflow

One of the twelve API operations that build or publish things on the platform.

## Quick facts

- Number of API workflows: 12
- Object created by every publish: deployment
- Object that holds records: table
